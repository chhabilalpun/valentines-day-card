# 💖 Interactive Valentine's Day Asking Webpage

A fun, interactive, and romantic web application designed to ask your special someone to be your Valentine. Built with pure HTML, CSS, and JavaScript.

![Uploading valentine_day_ss.png…]()

## ✨ Features

- **Interactive "No" Button:** Every time the user clicks "No", the button moves to a random position on the screen to playfully prevent them from rejecting you.
- **Dynamic Text & Images:** The "No" button text changes with cute, persuasive messages, and the central image changes dynamically with funny reaction memes.
- **Growing "Yes" Button:** To encourage a "Yes", the "Yes" button grows bigger with every attempt to click "No"!
- **Self-Contained Starting Image:** Uses an embedded Base64 URI for the default image, ensuring fast load times without external image dependencies on launch.

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` directly in any web browser.
3. Share it with your Pookie! ❤️

## 🛠️ Built With

- **HTML5** – Page structure and content
- **CSS3** – Styling, transitions, and layout
- **JavaScript (Vanilla)** – Dynamic button positioning, image cycling, and event handling
